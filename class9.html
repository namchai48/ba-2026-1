📈 Linear Regression — ลากเส้นตรงที่พอดีกับข้อมูลที่สุด

โจทย์: ทำนายผลผลิตต่อไร่ จากอุณหภูมิสูงสุดในสัปดาห์ก่อนเก็บเกี่ยว

ภาพตัวอย่างของสิ่งที่เราจะสร้าง: จุดสีเทาคือรอบเก็บเกี่ยวจริง · เส้นตรงสีเขียวคือเส้นที่ Linear Regression ลากให้ผ่านใกล้จุดทั้งหมดมากที่สุด — ยิ่งอุณหภูมิสูง เส้นยิ่งลงต่ำ แปลว่าผลผลิตลดลง

Linear Regression (การถดถอยเชิงเส้น) หาเส้นตรง y = m·x + b ที่ผ่านใกล้จุดข้อมูลทั้งหมดมากที่สุด · m คือความชัน (coefficient) และ b คือจุดตัดแกน y (intercept) — คือเส้น Trendline แบบ Linear ที่เคยกดใส่ในกราฟกระจายของ Excel นั่นเอง

MAEMean Absolute Error — ค่าเฉลี่ยของความผิดพลาด (ไม่สนเครื่องหมาย)MAE = (1/n) · Σ |yᵢ − ŷᵢ|ทายพลาดเฉลี่ย 1.68 กก./ไร่ต่อรอบ · หน่วยเดียวกับ target จึงอธิบายผู้จัดการได้ง่ายที่สุดต่ำ
RMSERoot Mean Squared Error — ยกกำลังสองความผิดพลาดก่อนเฉลี่ย แล้วถอดรากRMSE = √[ (1/n) · Σ (yᵢ − ŷᵢ)² ]2.05 กก. · สูงกว่า MAE เพราะมีบางรอบที่พลาดหนัก · ใช้เมื่อการพลาดหนักครั้งเดียวเสียหายมาก เช่น รับออเดอร์เกินกว่าที่ผลิตได้จริงต่ำ
MAPEMean Absolute Percentage Error — ความผิดพลาดเป็นเปอร์เซ็นต์ของค่าจริงMAPE = (100/n) · Σ |(yᵢ − ŷᵢ) / yᵢ|พลาดเฉลี่ย 18.7% · ใช้เทียบข้ามสินค้าที่หน่วยหรือขนาดต่างกันได้ต่ำ
R²R-squared — สัดส่วนความผันแปรของ target ที่โมเดลอธิบายได้ (0 ถึง 1)R² = 1 − Σ (yᵢ − ŷᵢ)² / Σ (yᵢ − ȳ)²อุณหภูมิอย่างเดียวอธิบายความขึ้นลงของผลผลิตได้ราว 40% · อีก 60% มาจากปัจจัยอื่นที่ยังไม่ได้ใส่สูง

สัญลักษณ์: n = จำนวนแถวในชุดทดสอบ (454) · yᵢ = ค่าจริงของแถวที่ i · ŷᵢ = ค่าที่โมเดลทำนายของแถวที่ i · ȳ = ค่าเฉลี่ยของค่าจริงทั้งชุด · Σ = รวมทุกแถว · |…| = ค่าสัมบูรณ์ (ตัดเครื่องหมายลบ)

⚠️ ข้อควรระวังของ MAPE — ถ้าค่าจริงเป็น 0 หรือใกล้ 0 การหารจะทำให้ MAPE พุ่งเป็นหลักร้อยหลักพันเปอร์เซ็นต์ · ข้อมูลของเราต่ำสุด 2.31 กก./ไร่ จึงยังใช้ได้ · แต่ถ้าทำนายผลผลิต รายวัน ซึ่งบางวันไม่ได้เก็บเลย (= 0) ห้ามใช้ MAPE ให้ใช้ MAE แทน

💡 ทางเลือก: WMAPE (Weighted MAPE) — ถ้ายังอยากได้ตัวเลขเป็นเปอร์เซ็นต์ ให้ลองใช้ WMAPE แทน MAPE · แทนที่จะหารความผิดพลาดทีละแถว จะรวมความผิดพลาดทุกแถวก่อน แล้วหารด้วยผลรวมของค่าจริง จึงไม่พังเมื่อมีบางแถวเป็น 0 และแถวที่ค่าจริงน้อย ๆ ไม่ทำให้ตัวเลขพุ่ง (แถวที่ค่าจริงมากมีน้ำหนักมากกว่า) · เหมาะกับงานอย่างยอดขายหรือผลผลิตรายวันที่มีวันที่เป็น 0 บ่อย
