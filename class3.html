Power Query คือ?

คือ เครื่องมือเตรียมข้อมูล (Data Preparation) ที่ช่วยเปลี่ยนข้อมูลที่ใช้งานไม่ได้หรือใช้งานยาก ให้พร้อมสำหรับการวิเคราะห์ โดยที่ ไม่ต้องเขียนสูตร อีกทั้งยังสามารถ บันทึกขั้นตอนการจัดการข้อมูลไปใช้ซ้ำได้

ทำไมต้องใช้ Power Query?

ลักษณะการทำงานExcel แบบเดิม (Standard Excel)Power Query
การทำงานทำซ้ำด้วยมือ (Manual)บันทึกขั้นตอนอัตโนมัติ (Automated Steps)
ความปลอดภัยแก้ไขทับข้อมูลเดิม (Destructive)ข้อมูลต้นทางปลอดภัยเสมอ (Non-destructive)
ปริมาณข้อมูลทำงานช้าเมื่อเจอข้อมูลขนาดใหญ่จัดการข้อมูลได้ระดับล้านแถวอย่างรวดเร็ว
ความยืดหยุ่นสูตรซับซ้อนแก้ไขยากแก้ไขแต่ละขั้นตอนได้อิสระ

เทียบให้เห็นภาพ: ทำมือ vs Power Query

❌ วิธีเดิม (ทำมือทุกเดือน)

  • เปิด 3 ไฟล์ ก็อปวางต่อกัน
  • ลบบรรทัดหัวรายงานทีละไฟล์
  • ไล่ลบแถวซ้ำด้วยตา
  • แยกคอลัมน์ด้วย Text to Columns
  • VLOOKUP ดึงชนิดพืช
  • เดือนหน้า → ทำใหม่ทั้งหมด (≈45 นาที)

✅ วิธี Power Query

  • Get Data → From Folder (ครั้งเดียว)
  • คลิกขั้นตอนทำความสะอาด (ครั้งเดียว)
  • Append + Merge (ครั้งเดียว)
  • Close & Load
  • วางไฟล์ใหม่ในโฟลเดอร์
  • เดือนหน้า → กด Refresh All (≈5 วินาที)

Applied Steps — สมุดบันทึกขั้นตอน

ทุกครั้งที่คลิก Power Query จะจดไว้ที่แถบขวามือ ชื่อว่า Applied Steps ลบ/แก้/สลับลำดับได้ตลอดเวลา — นี่คือสิ่งที่ทำให้ทำซ้ำได้

⚠️ ลำดับสำคัญมาก: ถ้า Use First Row as Headers ก่อน Remove Top Rows หัวตารางจะกลายเป็น "รายงานข้อมูลเซนเซอร์…" ทันที ลองสลับดูจะเห็นว่าพังทั้งคิวรี

🔠 หัวตาราง (Headers)

  • Use First Row as Headers ใช้แถวแรกเป็นหัวตาราง
  • Use Headers as First Row ใช้หัวตารางเป็นแถวแรก (ย้อนกลับ — ใช้เมื่อ Power Query เดาหัวตารางผิด)

✨ Format — การปรับรูปแบบของข้อมูล

อยู่ที่แท็บ Transform → Format (ใช้กับคอลัมน์ชนิดข้อความ)

  • lowercase ปรับเป็นตัวพิมพ์เล็ก
  • UPPERCASE ปรับเป็นตัวพิมพ์ใหญ่
  • Capitalize Each Word ปรับเป็นตัวพิมพ์ใหญ่เฉพาะตัวแรกของคำ
  • Trim ลบช่องว่างหน้า–หลัง
  • Clean ลบอักขระที่มองไม่เห็น เช่น Tab
  • Add Prefix เพิ่มคำนำหน้า
  • Add Suffix เพิ่มคำลงท้าย
💡 ใช้จริงบ่อยที่สุด: Trim + Clean เพื่อจัดการช่องว่างส่วนเกิน แล้วตามด้วย Capitalize Each Word ให้ชื่อสินค้า/หมวดหมู่เขียนเหมือนกันทั้งคอลัมน์ — ไม่งั้น PivotTable จะนับ "melon" กับ "Melon" เป็นคนละรายการ
คู่มืออ้างอิง

✂️ Split Column — แยกข้อมูลเดิมออกเป็นคอลัมน์ใหม่

  • By Delimiter แยกด้วยตัวคั่น (เช่น - , ช่องว่าง) — ใช้บ่อยที่สุด
  • By Number of Characters แยกตามจำนวนตัวอักษร
  • By Positions แยกตามตำแหน่ง
  • By Lowercase to Uppercase จากตัวพิมพ์เล็กเป็นตัวพิมพ์ใหญ่
  • By Uppercase to Lowercase จากตัวพิมพ์ใหญ่เป็นตัวพิมพ์เล็ก
  • By Digit to Non-Digit จากตัวเลขเป็นตัวอักษร
  • By Non-Digit to Digit จากตัวอักษรเป็นตัวเลข
✅ ตัวอย่างในแบบฝึกหัด: คอลัมน์ Route ที่เก็บ "กรุงเทพ-ชลบุรี" → ใช้ By Delimiter ด้วยเครื่องหมาย - แยกเป็น Origin กับ Destination แล้วตามด้วย Trim จัดการช่องว่างส่วนเกิน

Advanced Editor

👨‍💻 ทุกคลิกของคุณ = โค้ด M

Power Query เขียนภาษา M ให้อัตโนมัติ เราไม่ต้องเขียนเองตั้งแต่ต้น แต่ ต้องอ่านออก เพื่อแก้เมื่อคิวรีพัง — เลือกขั้นตอนด้านล่างเพื่อดูโค้ดที่ถูกสร้าง

กายวิภาคของโค้ด M

let Source = Csv.Document(File.Contents("C:\Farm\sensorA.csv")), RemovedTop = Table.Skip(Source, 3), Promoted = Table.PromoteHeaders(RemovedTop), Typed = Table.TransformColumnTypes(Promoted, {{"อุณหภูมิ", type number}}), NoDup = Table.Distinct(Typed) in NoDup
อ่านจากบนลงล่าง: แต่ละบรรทัดรับผลลัพธ์จากบรรทัดก่อนหน้ามาแปลงต่อ แล้วส่งชื่อขั้นตอนสุดท้ายออกหลัง in
