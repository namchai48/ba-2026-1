👥 K-Nearest Neighbors (KNN)

หลักการ: ออเดอร์ใหม่น่าจะมีผลเหมือนออเดอร์ในอดีตที่หน้าตาคล้ายมันที่สุด — หาออเดอร์เก่าที่ใกล้ที่สุด K รายการ แล้วดูว่าส่วนใหญ่ล่าช้าหรือไม่

  1. รับออเดอร์ใหม่เข้ามา (ปรับสเกลแล้ว)
  2. วัดระยะห่างจากออเดอร์ใหม่ไปยังออเดอร์ในชุดฝึกทุกรายการ
  3. เลือก K รายการที่ใกล้ที่สุด
  4. นับเสียง — ถ้าเกินครึ่งล่าช้า ก็ทายว่าล่าช้า · สัดส่วนเสียงคือความน่าจะเป็น

KNN ไม่มีขั้นตอน "เรียน" จริง ๆ ตอน fit แค่จำข้อมูลฝึกไว้ทั้งหมด งานหนักเกิดตอน predict

K-Means ทำงานอย่างไร — 5 ขั้นตอน

  1. กำหนดจำนวนกลุ่ม K ที่ต้องการ
  2. สุ่มจุดเริ่มต้น K จุด เป็นจุดศูนย์กลาง (centroid) ของแต่ละกลุ่ม
  3. ข้อมูลแต่ละจุดเข้ากลุ่มของจุดศูนย์กลางที่ใกล้ที่สุด
  4. ย้ายจุดศูนย์กลางไปอยู่ที่ค่าเฉลี่ยของสมาชิกในกลุ่ม
  5. ทำขั้น 3–4 ซ้ำ จนจุดศูนย์กลางไม่ขยับอีก
🔗 ใช้ระยะห่างเหมือน KNN ที่เพิ่งเรียน → ต้องปรับสเกลก่อนเสมอ · แต่ K ของ K-Means คือจำนวนกลุ่ม ไม่ใช่จำนวนเพื่อนบ้าน — ชื่อคล้ายกันแต่คนละเรื่อง

from sklearn.model_selection import train_test_split # import ก่อนเรียกใช้เสมอ from sklearn.preprocessing import StandardScaler from sklearn.neighbors import KNeighborsClassifier from sklearn.metrics import confusion_matrix, classification_report df['y'] = (df['ล่าช้า'] == 'ใช่').astype(int) # 1. target เป็น 0/1 features = ['ระยะทาง (กม.)', 'มูลค่าออเดอร์ (บาท)', 'แจ้งล่วงหน้า (ชม.)', 'งานค้างแพ็ก (ออเดอร์)'] X, y = df[features], df['y'] # ห้ามใช้คอลัมน์ที่รู้หลังส่ง X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42, stratify=y) # 2. แบ่ง scaler = StandardScaler().fit(X_train) # 3. ปรับสเกล (fit เฉพาะชุดฝึก) Xs_train, Xs_test = scaler.transform(X_train), scaler.transform(X_test) knn = KNeighborsClassifier(n_neighbors=9).fit(Xs_train, y_train) # 4. ฝึก ← เทียบคาบ 9: เปลี่ยนแค่ชื่อโมเดล y_pred = knn.predict(Xs_test) # 5. ทำนาย print(confusion_matrix(y_test, y_pred)) # 6. วัดผล print(classification_report(y_test, y_pred, digits=3)) new = pd.DataFrame([[96, 9000, 20, 6]], columns=features) # 7. ใช้กับออเดอร์ใหม่ print(knn.predict_proba(scaler.transform(new))) # ต้อง transform ก่อนเสมอ
